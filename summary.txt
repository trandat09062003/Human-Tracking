--------------------------------------------------------------------------------
1. MỤC TIÊU
--------------------------------------------------------------------------------

Video kiểu CCTV / screen recording (khoảng 1880×1060, ~30 FPS). Cần:

  - Detect người, gán ID ổn định qua thời gian
  - Ít false positive (xe đạp / xe máy hay bị YOLO nhận thành person khi conf thấp)
  - Ít ID switch khi hai người gần nhau hoặc che nhau
  - Ít ID mới oan sau khi mất detection vài giây (occlusion / miss)
  - Đếm người cắt một đường ảo trên lòng đường, hướng phải → trái (RTL)

Máy chạy chủ yếu CPU → chấp nhận FPS không cao, ưu tiên ID đúng.


--------------------------------------------------------------------------------
2. PIPELINE
--------------------------------------------------------------------------------

  Frame video
      │
      ▼
  (1) YOLO11 detect — best_v5.pt
      Ultralytics YOLO.predict(), classes=[0]
      imgsz=640, DETECT_CONF=0.28
      │
      ▼
  (2) Pre-filter (TRƯỚC tracker)
      - conf >= TRACK_CONF (0.42)
      - aspect / chiều cao / diện tích tối thiểu
      - nested containment (box nhỏ nằm trong box lớn)
      - overlap NMS thủ công (IoU)
      → FP và double-box không được cấp ID
      │
      ▼
  (3) BoT-SORT
      BOTSORT.update(), config: custom_tracker.yaml
      Kalman + association kiểu ByteTrack (high/low score)
      track_buffer giữ lost tracks
      → raw track ID
      │
      ▼
  (4) Prune raw tracks chồng IoU cao
      │
      ▼
  (5) IDRecoverer
      raw_id → stable_id
      Hungarian + HSV torso + velocity
      khôi phục ID sau miss / occlusion ngắn
      │
      ▼
  (6) Suppress overlapping stable IDs
      2 ID chồng → giữ hits cao / ID cũ hơn
      ID thừa demote sang lost (hoặc alias về ID giữ lại)
      │
      ▼
  (7) LineCounter
      điểm chân cắt đường đỏ, only_rtl=True
      │
      ▼
  (8) Vẽ box / nhãn / HUD / ghi *_tracked.mp4


Vì sao không dùng model.track() một phát:

  - Filter sau khi track thì ID rác đã tồn tại.
  - Cần IDRecoverer nằm trên BoT-SORT, không nhét được sạch vào API track mặc định.
  - Muốn demote / alias khi box trùng một cách tường minh.


--------------------------------------------------------------------------------
3. CÔNG NGHỆ DÙNG
--------------------------------------------------------------------------------

3.1. Ultralytics YOLO11 + best_v5.pt
  Detector. Fine-tune 1 class person trên data domain (đường phố / camera cố định).
  predict() tách khỏi track → chèn filter tùy ý.
  imgsz=640: thử 960/1280 trên clip dự án không cải thiện rõ, chậm hơn trên CPU.

3.2. PyTorch
  Backend suy luận. Có CUDA thì dùng GPU + half nếu bật; không thì CPU.

3.3. BoT-SORT (ultralytics.trackers.bot_sort.BOTSORT)
  Multi-object tracker cấp raw ID.
  Chọn BoT-SORT vì có Kalman dự đoán khi miss ngắn, cùng họ ByteTrack
  (association cả detection điểm thấp).
  with_reid=False: deep ReID nặng trên CPU, dễ chậm; appearance nhẹ để cho
  IDRecoverer (HSV).
  gmc_method=none: camera cố định, sparseOptFlow không giúp và đôi khi nhiễu.

3.4. IDRecoverer (trong local_tracking.py)
  Map raw → stable, recover sau occlusion.
  - linear_sum_assignment (SciPy)
  - cost: dist tới vị trí dự đoán + hist HSV thân + (1−IoU) + area ratio
  - cổng chống neighbor-steal
  - teleport cut khi nhảy xa VÀ appearance khác rõ
  - nearest-lost fallback trong bán kính

3.5. LineCounter
  Đường chuẩn hóa COUNT_LINE_NORM.
  Điểm track: chân (bottom-center box) nếu USE_FOOT_POINT=True.
  Cắt đường = giao đoạn OR đổi phía (dấu cross product 2D).
  only_rtl: chỉ cộng khi dx <= 0.
  Mỗi stable_id đếm một lần.

3.6. OpenCV / NumPy / SciPy / PyYAML
  Video I/O, vẽ, HSV hist; toán box; Hungarian; đọc yaml tracker.


--------------------------------------------------------------------------------
4. THAM SỐ ĐANG DÙNG
--------------------------------------------------------------------------------

4.1. Detection (local_tracking.py)

  DETECT_CONF   = 0.28     candidate rộng
  TRACK_CONF    = 0.42     vào tracker; chặn FP xe đạp từng thấy ~0.39
  IOU           = 0.28     NMS YOLO chặt
  IMGSZ         = 640
  MAX_DET       = 50
  classes       = [0]      chỉ person

4.2. Pre-filter hình dạng / chồng box

  MIN_ASPECT        = 1.70
  MAX_ASPECT        = 7.00     người đứng CCTV thường ~2.0–4.6; xe đạp thấp hơn
  MIN_HEIGHT_RATIO  = 0.045
  MIN_BOX_AREA      = 600
  NEST_THRESH       = 0.40     box nhỏ nằm ≥40% trong box lớn → bỏ
  OVERLAP_IOU       = 0.25     IoU ≥ này → giữ box mạnh hơn
  TRACK_OVERLAP_IOU = 0.28     sau tracking: 2 ID chồng → giữ ID già hơn
  CENTER_DIST_RATIO = 0.40     tâm gần < 0.4×h → coi cùng người
  MIN_HITS          = 2        hiện track sau 2 frame

4.3. BoT-SORT (custom_tracker.yaml)

  track_high_thresh = 0.35
  track_low_thresh  = 0.12     association điểm thấp (ByteTrack-style)
  new_track_thresh  = 0.45     tạo raw ID mới
  track_buffer      = 150      ~5s @ 30fps
  match_thresh      = 0.80     Ultralytics: cost ≈ 1−IoU; cao = dễ match sau miss
  fuse_score        = True
  gmc_method        = none
  with_reid         = False

4.4. IDRecoverer

  RECOVER_MAX_FRAMES     = 150
  RECOVER_MAX_DIST_RATIO = 1.60   max_dist = 1.6 × chiều cao box đã mất
  RECOVER_COST_THRESH    = 0.72
  RECOVER_MAX_HIST       = 0.75   Bhattacharyya appearance
  RECOVER_MIN_IOU        = 0.0
  MAX_JUMP_RATIO         = 2.20

  Trọng số cost (ưu tiên vị trí):
    0.55 × dist_norm
  + 0.30 × hist_dist
  + 0.10 × (1 − IoU)
  + 0.05 × area_ratio

4.5. Line count

  COUNT_LINE_NORM = ((0.18, 0.58), (0.92, 0.72))
  USE_FOOT_POINT  = True
  only_rtl        = True
  RTL_DX_MIN      = 1.0 px

  Công thức phía điểm P so với đoạn A→B (thành phần z của u×w):
    v = (Bx−Ax)*(Py−Ay) − (By−Ay)*(Px−Ax)
    v > 0 / v < 0 = hai phía khác nhau; đổi dấu giữa 2 frame → có thể đã cắt đường.


--------------------------------------------------------------------------------
5. CHỈNH THAM SỐ THÌ SAO
--------------------------------------------------------------------------------

A) local_tracking.py

  Tham số                 | Tăng lên                         | Giảm xuống
  ------------------------|----------------------------------|---------------------------------
  DETECT_CONF             | ít nhiễu, dễ sót                 | bắt nhiều hơn, thêm FP
  TRACK_CONF              | ít FP xe đạp, dễ sót người mờ    | bắt người xa, dễ FP
  IOU (NMS)               | giữ nhiều box chồng              | ít double-box, dễ gộp 2 người
  MIN_ASPECT              | ít box ngang (xe), sót ngồi      | bắt tư thế thấp, thêm FP
  OVERLAP_IOU             | dễ gộp 2 người gần nhau          | cho box chồng nhiều hơn
  TRACK_OVERLAP_IOU       | dễ xóa 1 trong 2 ID gần          | cho 2 ID chồng hiển thị
  MIN_HITS                | ít ID nháy                       | hiện track sớm hơn
  RECOVER_MAX_FRAMES      | giữ ID lâu sau mất               | quên nhanh, ít cướp ID
  RECOVER_COST_THRESH     | dễ khôi phục ID cũ               | khó recover, nhiều ID mới
  RECOVER_MAX_DIST_RATIO  | recover xa hơn                   | chỉ recover rất gần
  RECOVER_MAX_HIST        | nới appearance                   | bắt buộc giống màu áo hơn
  MAX_JUMP_RATIO          | ít cắt ID khi box giật           | cắt nhanh khi nhảy vị trí

B) custom_tracker.yaml

  Tham số                 | Tăng lên                         | Giảm xuống
  ------------------------|----------------------------------|---------------------------------
  track_buffer            | giữ lost lâu (che khuất)         | ít gán nhầm sau mất lâu
  match_thresh            | dễ khớp IoU thấp sau miss        | khớp chặt, ít ID switch
  new_track_thresh        | ít raw ID mới                    | tạo track nhanh, dễ rác
  track_high_thresh       | association “sạch” hơn           | giữ track conf thấp hơn
  track_low_thresh        | ít dùng detection yếu            | bắt detection rất yếu


--------------------------------------------------------------------------------
6. NHỮNG GÌ ĐÃ THỬ / TRADE-OFF
--------------------------------------------------------------------------------

  - TRACK_CONF ≤ ~0.30: xe đạp/FP nhận ID, Unique tăng loạn.
  - new_track_thresh ~0.85: sót người thật.
  - track_buffer ngắn + recover chặt: che khuất nhẹ đã ra ID mới.
  - recover lỏng + buffer dài: ID nhảy sang người đứng cạnh.
  - GMC sparseOptFlow trên cam cố định: không cải thiện rõ.
  - Lọc FP sau model.track(): vô ích vì ID đã cấp — phải lọc trước.
  - Không xử lý box chồng: 2 box 1 người → 2 ID tranh nhau.
  - Đếm bằng tâm box: dễ đếm sớm/muộn; chân ổn hơn trên đường ngang lòng đường.
  - Đếm cả LTR+RTL: số tăng nhanh, dễ nhiễu khi người đứng gần đường; hiện chỉ RTL.
  - Từng gắn thêm detector COCO xe (yolo11n): bỏ — scope chỉ người.
